# AtaDey — Product Context

## Purpose
AtaDey is a Turkish proverbs (atasözü) and idioms (deyim) quiz game. Users test their knowledge of Turkish language expressions through two modes: text-to-meaning and meaning-to-text.

## Audience
Turkish speakers of all ages who want to learn or test their knowledge of atasözleri and deyimler. Casual, educational, mobile-friendly.

## Operating Context
Web-based, client-side only. No backend, no Firebase. Runs entirely in the browser with static JSON question data.

## Constraints
- Single-page Vite + React application
- Client-side rendering only
- Static JSON data for questions (1000+ entries)
- Must work on mobile and desktop
- No external APIs

## Voice
Clear, friendly, educational. Turkish language. Encouraging but direct.

## Visual Direction
Blue-only palette (mavi tonlar). Outfit font (distinctive, not overused). No gradients, no bounce easing, no thick borders, no dark glows. Clean, modern, intentional design. Never AI slop.
